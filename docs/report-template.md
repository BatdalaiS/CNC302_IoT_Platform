| | 🥧 Raspberry Pi 3B | 💻 Зөөврийн компьютер |
|---|---|---|
| Загвар / процессор | | |
| RAM (нийт / боломжтой) | | |
| OS, цөмийн хувилбар | | |
| Сүлжээ (кабель / Wi-Fi, хурд) | | |
| Хадгалалт (microSD ангилал) | | |
| Docker хувилбар | | |

**Хэмжилтийн өмнөх шалгалт (🥧):**

| Шалгалт | Утга | Хэвийн үү |
|---|---|---|
| `vcgencmd get_throttled` | | `0x0` байх ЁСТОЙ |
| `vcgencmd measure_temp` | | < 70 °C |
| `free -m` → available | | > 400 MiB |
| `timedatectl` synchronized | | yes |
