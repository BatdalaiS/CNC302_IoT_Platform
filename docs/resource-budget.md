# Нөөцийн төсөв — хоёр давхаргат байрлуулалт

Энэ бол **чиглүүлэх тооцоо**. Бодит утгыг Лаб 1-д өөрсдөө хэмжинэ.

---

## 1. 🥧 Raspberry Pi 3B — 1 GB-ын арифметик

### Юу хаана явдаг вэ

| Хэсэг | MiB | Тэмдэглэл |
|---|---|---|
| Нийт физик санах ой | 1024 | |
| GPU-д (`gpu_mem=16`) | −16 | анхдагч 64 → 48 MiB хэмнэнэ |
| Цөм + firmware | ~85 | |
| **Системд харагдах (`MemTotal`)** | **~925** | `free -m` энийг харуулна |
| Pi OS Lite, headless, амарч байгаа | −90…−130 | systemd, sshd, journald |
| Docker демон | −60…−80 | `dockerd` + `containerd` |
| **Ажилд боломжтой** | **~720…780** | |

### Ирмэгийн үйлчилгээний төсөв

| Үйлчилгээ | Compose хязгаар | Бодит амралтын хэрэглээ | Тэмдэглэл |
|---|---|---|---|
| `mosquitto` | 128 MiB | 12–25 MiB | Дараалал дүүрэхэд өснө: 100k мессеж × 250 B ≈ 25 MiB |
| ирмэгийн агент (venv) | 200 MiB (systemd) | 45–70 MiB | numpy ~25 MiB эзэлнэ |
| + TFLite дүгнэлт (Лаб 6) | ↑ | +40…+90 MiB | загварын хэмжээ ба цонхноос хамаарна |
| VS Code Remote сервер | — | **150–250 MiB** | ⚠ хэмжилтийн өмнө таслах! |

**Нийлбэр (Лаб 1–5):** ~120 MiB → **600 MiB илүүдэлтэй.** Тав тухтай.
**Нийлбэр (Лаб 6, дүгнэлттэй):** ~200 MiB → **520 MiB илүүдэлтэй.** Хангалттай.
**Лаб 8 (K3s):** доорх §3-ыг үзнэ үү — энэ нь хамгийн чанга.

### Хэзээ анхаарах вэ

```bash
free -m | awk '/Mem:/{print $7 " MiB available"}'
```

| Үлдэгдэл | Утга |
|---|---|
| > 400 MiB | хэвийн |
| 150–400 MiB | болгоомжтой — шинэ үйлчилгээ нэмэхээс өмнө хэмж |
| < 150 MiB | **аюултай** — swap идэвхжиж, бүх саатал 10–100 дахин өснө |
| swap `si/so` > 0 | аль хэдийн хязгаарт хүрсэн. Энэ нь **хэмжилт**, алдаа биш. |

`tools/measure_stack.sh --role edge` эдгээрийг автоматаар шалгана.

## 3. 🥧 Лаб 8 — K3s-ийн санах ойн төсөв

Лаб 8-д Pi дээр **Docker-ийг зогсоож**, K3s-ийг ажиллуулна. Хоёуланг зэрэг ажиллуулах орон зай байхгүй.

| Хэсэг | Requests | Бодит |
|---|---|---|
| k3s server (containerd + kubelet + API + sqlite) | — | 250–350 MiB |
| coredns | 70 MiB | ~25 MiB |
| metrics-server (HPA-д ЗААВАЛ) | 70 MiB | ~30 MiB |
| local-path-provisioner | — | ~10 MiB |
| `mosquitto` pod | 64 MiB | 12–25 MiB |
| `edge-agent` pod | 64 MiB | 45–70 MiB |
| **Нийт requests** | **268 MiB** | |
| **Бодит нийлбэр** | | **~400–510 MiB** |
| Allocatable (925 − цөм − k3s үндэс) | ~825 MiB | |

**Дүгнэлт:** ажиллана, гэхдээ `traefik` ба `servicelb`-ийг заавал унтраана (тус бүр 60–90 MiB). HPA 2 хувь болтол өргөжиж чадна; 3 дахь хувь OOMKilled болно — **энэ нь Лаб 8-ын гол ажиглалт**.

```bash
curl -sfL https://get.k3s.io | sh -s - \
  --disable traefik --disable servicelb --write-kubeconfig-mode 644
```

## 4. Санамж

- `deploy.resources.limits` нь **хязгаар** л тавьдаг, нөөц **баталгаажуулдаггүй**. Pi дээр хязгаарыг давсан контейнерийг цөм OOM-оор устгана; лог нь `docker inspect <c> | grep OOMKilled`.
- `docker stats`-ын санах ойн тоо зөв гарахад `cgroup_enable=memory` хэрэгтэй (SETUP.md Б.5).
- Идэвхтэй хөргөлт байхгүй бол Pi 3B ачаалал дор 80 °C давж, давтамжаа бууруулна — бүх хэмжилт гажина. `vcgencmd get_throttled` нь **`0x0`** байх ёстой.
- microSD-гийн бичих хурд (10–25 MB/s) нь InfluxDB, mosquitto persistence, swap гурвыг зэрэг хязгаарлана. Лаб 5-д үүнийг бодитоор хэмжинэ.
- Хэмжилтийн өмнө **VS Code Remote серверийг таслах**: `pkill -f vscode-server`. 150–250 MiB ялгаа гарна.
