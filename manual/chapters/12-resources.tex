\section{3. Лаб 8 --- K3s: server нь VM дээр, Pi нь agent}\label{ux43bux430ux431-8-k3s-server-ux43dux44c-vm-ux434ux44dux44dux440-pi-ux43dux44c-agent}}

Тиймээс K3s \textbf{server} нь зөөврийн компьютер дээрх Ubuntu Server VM-д, Raspberry Pi 3B нь зөвхөн \textbf{agent} болж нэгдэнэ (дэлгэрэнгүй: \texttt{lab08/\allowbreak{}k3s/\allowbreak{}README.\allowbreak{}md}). \textbf{HPA-ийн гол зөрчил (Лаб 8):} товлогчийн тооцоогоор \texttt{32\ +\ 96·N\ ≤\ 925} → \textbf{N\_sched ≈ 9} хүртэл "багтана". \section{4. Санамж}\label{ux441ux430ux43dux430ux43cux436}}

\begin{itemize}
\tightlist
\item
  \texttt{deploy.\allowbreak{}resources.\allowbreak{}limits} нь \textbf{хязгаар} л тавьдаг, нөөц \textbf{баталгаажуулдаггүй}. Pi дээр хязгаарыг давсан контейнерийг цөм OOM-оор устгана; лог нь \texttt{docker\ inspect\ \textless{}c\textgreater{}\ \textbar{}\ grep\ OOMKilled}.
\item
  Cgroup-ийн санах ойн хянагч (\texttt{cgroup\_\allowbreak{}memory=\allowbreak{}1\ cgroup\_\allowbreak{}enable=\allowbreak{}memory}) нь \texttt{docker\ stats}-ын санах ойн тоо ба K3s agent-д хэрэгтэй (SETUP.md Б.5).
\item
  Идэвхтэй хөргөлт байхгүй бол Pi 3B ачаалал дор 80--85 °C-д хүрч давтамжаа бууруулна --- бүх хэмжилт гажина. \texttt{vcgencmd\ get\_\allowbreak{}throttled} нь \textbf{\texttt{0x0}} байх ёстой.
\item
  microSD-гийн бичих хурд нь mosquitto persistence ба swap-ыг зэрэг хязгаарлана. Лаб 5-д үүнийг бодитоор хэмжинэ.
\item
  Хэмжилтийн өмнө \textbf{VS Code Remote серверийг таслах}: \texttt{pkill\ -f\ vscode-server}. VS Code-ийн баримтаар Remote-SSH-ийн хостод 1 GB RAM \emph{шаардлагатай} --- Pi 3B-д энэ бол том зардал; ялгааг Лаб 1-д хэмж.
\end{itemize}
